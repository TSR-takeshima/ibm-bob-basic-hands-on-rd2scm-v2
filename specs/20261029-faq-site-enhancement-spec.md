* 更新日時: 2026-10-29T14:48:59+09:00

## 背景・目的

既存の日本語FAQサイト（`index.html` / `style.css` / `script.js`）に対して、ブランドロゴの表示・リンク付与・IBMブルーへのテーマカラー変更・ダークテーマ切り替えの4機能を追加する。

## 現在の挙動

- ヘッダーにはテキストタイトル「よくある質問」のみ表示されている
- テーマカラーはグレー系（`#4b5563`）
- ダークテーマは未対応

## 期待する挙動

1. ヘッダー左上に `bob.svg` が高さ48pxで表示される
2. ロゴをクリックすると `https://www.ibm.com/products/bob` が新しいタブで開く
3. テーマのアクセントカラーが `#0f62fe`（IBM Blue）に変更される
4. ヘッダー右上の 🌙/☀️ ボタンでダーク/ライトテーマを切り替えられる

## 対象範囲・対象外

### 対象範囲

- `index.html` — ロゴ画像・リンク・ダークテーマ切り替えボタンの追加
- `style.css` — テーマカラー変更・ダークテーマCSSの追加
- `script.js` — ダークテーマ切り替えロジックの追加

### 対象外

- FAQデータの変更
- タブ・アコーディオン・検索ロジックの変更
- 新規ファイルの作成

## 利用者・影響システム

- FAQサイトを参照するユーザー
- 既存の `script.js` の FAQデータ・タブ・アコーディオン・検索ロジックは変更しない

## 主な仕様

### 1. ロゴ画像の挿入

- `bob.svg` をヘッダー左上に `<img>` タグで表示する
- サイズ: 高さ48px（幅はアスペクト比維持）
- alt属性: `"IBM Bob"`

### 2. 画像へのリンク付与

- ロゴ画像を `<a href="https://www.ibm.com/products/bob" target="_blank" rel="noopener noreferrer">` で囲む

### 3. テーマカラーの変更（IBM Blue）

`style.css` のCSS変数を以下のように変更する。

| 変数名 | 変更前 | 変更後 |
|---|---|---|
| `--color-accent` | `#4b5563` | `#0f62fe` |

タブのアクティブ状態・フォーカスボーダー等に反映される。

### 4. ダークテーマの追加

- ヘッダー右上に切り替えボタンを配置する（`<button id="theme-toggle">`）
- ライトモード時: 🌙（ダークに切り替えるボタン）
- ダークモード時: ☀️（ライトに切り替えるボタン）
- `<html>` 要素に `data-theme="dark"` 属性を付与してテーマを切り替える
- テーマ状態を `localStorage` に保存し、ページ再読み込み時に復元する
- CSSは `[data-theme="dark"]` セレクタでダークテーマ変数をオーバーライドする

#### ダークテーマのカラー定義

| 変数名 | ダーク値 |
|---|---|
| `--color-bg` | `#161616` |
| `--color-surface` | `#262626` |
| `--color-border` | `#393939` |
| `--color-text` | `#f4f4f4` |
| `--color-muted` | `#a8a8a8` |
| `--color-accent` | `#4589ff` |

## 制約・非機能要件

- 外部ライブラリ・フレームワーク不使用
- `localStorage` でテーマ状態を永続化
- ダークテーマのカラーはIBM Carbon Design Systemのダークパレットに準拠

## UI・画面仕様

### 対象画面

FAQサイト（`index.html`）のヘッダー部分

### 画面構成・表示項目

**ヘッダー変更後の構成:**

```
┌──────────────────────────────────────────────────────┐
│  [bob.svg ロゴ 48px] よくある質問        [🌙 / ☀️]  │
└──────────────────────────────────────────────────────┘
```

- 左側: `bob.svg` ロゴ（リンク付き）＋「よくある質問」テキスト（横並び）
- 右側: ダークテーマ切り替えボタン

### 操作・画面遷移

| 操作 | 動作 |
|---|---|
| ロゴをクリック | `https://www.ibm.com/products/bob` を新しいタブで開く |
| 🌙 ボタンをクリック | ダークテーマに切り替え、ボタンが ☀️ に変わる |
| ☀️ ボタンをクリック | ライトテーマに切り替え、ボタンが 🌙 に変わる |

### 表示状態

| 状態 | 表示 |
|---|---|
| ライトテーマ（初期） | 白背景・IBMブルーアクセント・🌙ボタン |
| ダークテーマ | 暗い背景・明るい文字・ライトブルーアクセント・☀️ボタン |
| `localStorage` にダーク設定あり | ページ読み込み時にダークテーマで表示 |

### 入力・バリデーション

なし（ボタンのクリック操作のみ）

### デザイン要件

- ヘッダー内のロゴとタイトルは横並び（Flexbox）で左揃え
- 切り替えボタンはヘッダー右端に配置
- ボタンはアイコンのみ（背景透過・ボーダーなし）、ホバー時に背景色を表示
- ダークテーマはIBM Carbon Design Systemのダークパレット準拠

## 確認方法

1. `index.html` をブラウザで開いてロゴが左上に表示されることを確認
2. ロゴをクリックして正しいURLが新しいタブで開くことを確認
3. タブのアクティブ状態・検索フォーカスがIBMブルーになっていることを確認
4. 🌙 ボタンをクリックしてダークテーマに切り替わることを確認
5. ☀️ ボタンをクリックしてライトテーマに戻ることを確認
6. ダークテーマ状態でページを再読み込みして状態が維持されることを確認
7. Chrome DevToolsでモバイル表示（375px幅）を確認

## リスク・懸念点

- `localStorage` は同一オリジン制約があるが、ローカルファイル（`file://`）でも動作する
- `bob.svg` のパスはHTMLファイルからの相対パスで参照するため、ファイル移動時に注意が必要
