## 背景・目的

`qa.md` に記載されたFAQ情報を日本語化し、バックエンドなしでブラウザから直接参照できるスタティックなFAQサイトとして提供する。

## 現在の挙動

`qa.md` に英語でFAQが記述されているが、Webブラウザで閲覧・検索できる形にはなっていない。

## 期待する挙動

- ブラウザで `index.html` を開くと日本語のFAQサイトが表示される
- カテゴリタブ（General / 使い方 / 高度な機能 / トラブルシューティング）で内容を絞り込める
- 各Q&Aはアコーディオン形式で展開・折りたたみができる
- キーワード検索でQ&Aをリアルタイムフィルタリングできる

## 対象範囲・対象外

### 対象範囲

- `index.html`（FAQサイト本体）
- `style.css`（スタイルシート）
- `script.js`（インタラクション制御）

### 対象外

- バックエンドAPI、サーバーサイド処理
- 外部ライブラリ・フレームワークの導入
- CMS、データベース
- ビルドツール（Webpack、Vite等）

## 利用者・影響システム

- FAQを参照するユーザー（デスクトップ・スマートフォン）
- 既存ファイルへの影響なし（新規ファイルのみ追加）

## 主な仕様

### FAQデータ

`qa.md` のFAQ内容を日本語に翻訳して `script.js` 内にデータとして埋め込む。

カテゴリと日本語訳は以下の通り。

| 英語カテゴリ | 日本語タブ名 |
|---|---|
| General | 全般 |
| Usage | 使い方 |
| Advanced Features | 高度な機能 |
| Troubleshooting | トラブルシューティング |

### タブ切り替え

- 初期表示は「全般」タブが選択された状態
- タブをクリックすると対応カテゴリのQ&Aのみ表示される
- 検索中はすべてのカテゴリを横断して検索結果を表示する

### アコーディオン

- 初期状態はすべて折りたたまれている
- Qクリックで展開・折りたたみをトグルする
- 複数を同時に展開可能

### キーワード検索

- 検索ボックスへの入力をリアルタイムで検出（`input`イベント）
- 質問文・回答文の両方を検索対象とする
- 検索ワードが入力されている間はカテゴリタブのフィルタを無効化し、全カテゴリを横断検索する
- 検索結果が0件の場合は「該当する項目がありません」を表示する
- 検索ボックスをクリアすると通常のタブ表示に戻る

## 制約・非機能要件

- バックエンド不使用（スタティックファイルのみ）
- 外部CDN・ライブラリ不使用（純粋なHTML/CSS/JavaScript）
- レスポンシブデザイン（デスクトップ・スマートフォン対応）
- モダンブラウザ（Chrome, Firefox, Safari, Edge 最新版）を対象とする

### 対象画面

FAQサイト（単一ページ `index.html`）

```

│  ▶ Q: Bobとは何ですか？                   │
│  ──────────────────────────────────────  │
│  ▶ Q: Bobはどのように動作しますか？       │
│  ──────────────────────────────────────  │
│  ...                                      │
└──────────────────────────────────────────┘
```

### 操作・画面遷移

| 操作 | 動作 |
|---|---|
| カテゴリタブをクリック | 対応カテゴリのQ&Aのみ表示 |
| Q&Aをクリック | 回答を展開 / 折りたたみ |
| 検索ボックスに入力 | リアルタイムでQ&Aをフィルタリング |
| 検索ボックスをクリア | 通常のタブ表示に戻る |

### 表示状態

| 状態 | 表示 |
|---|---|
| 初期表示 | 「全般」タブ選択、全Q&A折りたたみ状態 |
| タブ選択時 | 選択カテゴリのQ&Aのみ表示 |
| 検索中 | タブ非活性、全カテゴリを横断してフィルタリング |
| 検索結果0件 | 「該当する項目がありません」メッセージを表示 |
| アコーディオン展開時 | 回答テキストを表示、矢印アイコンを回転 |

### 入力・バリデーション

- 検索ボックス：テキスト入力（バリデーションなし）
- 大文字・小文字を区別しない（case-insensitive）検索

### デザイン要件

- 背景色：白（`#ffffff`）
- アクセントカラー：グレー系（例: `#4b5563` / `#6b7280` / `#e5e7eb`）
- フォント：システムフォント（`system-ui, sans-serif`）
- タブのアクティブ状態：ダークグレーの下線または背景色で強調
- アコーディオン展開時：矢印アイコンを90度または180度回転
- モバイル対応：タブは横スクロールまたは折り返し対応
